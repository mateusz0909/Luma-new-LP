# Critical Thinking Skill Reference

Apply rigorous, evidence-aware reasoning to coding, architecture, debugging, reviews, front-end and UI/UX, and decision-making; surface assumptions, risks, edge cases, and better alternatives before agreeing.

- Surface weaknesses first.
- Demand empirical evidence.
- Verify claims directly through code execution and DOM / HTML checks.
- Stress-test boundary conditions and zero-JS / crawler rendering.
